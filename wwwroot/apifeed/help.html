Using the API app

Before you start

Serve the app over HTTPS or from localhost. Your browser must be able to connect directly to both Hevy and Intervals.icu; the app does not use a server-side proxy.

Get a Hevy API key

  1. Read Hevy's official API documentation and follow Hevy's current instructions for API access.
  2. The published API documentation identifies the credential as an API key sent in the api-key request header, but does not document a self-service key-generation location. If you cannot obtain a key through Hevy, contact Hevy support to request API access.
  3. Do not enter your Hevy account password here. Use only an API key issued or approved by Hevy.

Get an Intervals.icu API key

In Intervals.icu, open your account or athlete settings and find the API key option. Copy that key for the upload field. Keep it private; it is separate from your Hevy key.

Fetch and choose workouts

  1. Enter the Hevy API key in the Hevy API key field.
  2. Choose the timezone to use for the activity's local start time.
  3. Select Fetch. The app retrieves up to 10 workouts per page. Use First, Previous, Next, and Last to navigate.
  4. Select individual workouts, or use Select all to select every workout on the current page. Selection is cleared when you fetch another page.
  5. Optionally choose Download JSON to save the selected activities before uploading.

Upload selected activities

  1. Enter your Intervals.icu API key in the Intervals.icu API key field.
  2. Select Upload selected to intervals.icu. Only checked workouts on the current page are sent.
  3. Review the response or any error shown by the app. If browser access is blocked, check whether the API allows cross-origin requests from where this app is hosted.
API keys are held only in the current page and sent to their respective API. Do not share screenshots containing keys, and close the app tab when finished.
