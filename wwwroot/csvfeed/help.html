CSV FEED GUIDE

Using the CSV app

Back to app

Export your workouts from Hevy

  1. In the Hevy app, go to Profile → Settings → Export & Import Data → Export Data.
  2. Choose Export Workouts, not Export Measurements.
  3. Save or share the workout export to your device. If it arrives in an archive, extract it and choose the workout CSV file.

See Hevy's official data export instructions if the menu or export process differs on your device.

Convert and review the CSV

  1. Choose the workout CSV in the Workout CSV field.
  2. Choose the timezone used to interpret workout start and end times. The browser's timezone is selected by default.
  3. Select Convert CSV. The app groups exercise rows into workouts and shows a preview.
  4. The export needs the columns title, start_time, end_time, and exercise_title. The weight_kg and reps columns are used to calculate lifted volume.

Select and upload workouts

  1. Select individual workouts using their checkboxes, or use Select all to select every converted workout.
  2. Enter your Intervals.icu API key in the app. It is used only for the upload request and is not included in the exported activities.
  3. Select Upload selected to intervals.icu. Only checked workouts are uploaded.
  4. Download JSON saves all converted activities, regardless of checkbox selection, so you can keep or inspect the full conversion.
Your CSV is processed in this browser. Review the selected activities before uploading, and keep your Intervals.icu API key private.
